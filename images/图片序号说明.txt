图片序号说明
============

本目录存放「菜品图片」，文件名 = 该菜的图片序号：

    图片序号 = 食堂号 + 楼层号 + 餐厅号 + 菜序号      （按十进制直接拼接）

示例：
    1211.svg  = 第一食堂 二楼(2F) 第1个餐厅 第1道菜   ← 用户指定的示例
    1212.svg  = 第一食堂 二楼 第1个餐厅 第2道菜
    1221.svg  = 第一食堂 二楼 第2个餐厅 第1道菜
    1111.svg  = 第一食堂 一楼(1F) 第1个餐厅 第1道菜
    2314.svg  = 第二食堂 三楼(3F) 第1个餐厅 第4道菜

目前目录里是自动生成的「占位示例图」（SVG，图上标有序号、菜名与价格）。

替换为真实照片：直接把照片命名为对应序号放入本目录即可，例如
    images/1211.png（或 .jpg / .jpeg / .webp）
页面会按 png → jpg → jpeg → webp → svg 的顺序自动优先使用真实照片，
无需修改任何代码。

菜序号顺序以 data/*.xlsx 中每家店的行顺序为准（第 1 行是表头，第 2 行起为第 1 道菜）。
