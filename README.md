# 交我吃 · 三食堂门店菜单（展示型网页项目）

一个纯静态（原生 HTML + CSS + JavaScript，无需构建工具、无需后端）的展示型网页项目：
左侧为导航菜单（公告 / 今天吃什么 / 三个食堂），右侧为内容区（公告板、食堂介绍、
菜品网格、随机推荐），点击菜品卡片可弹出详情模态框。数据全部内置，打开即用。

## 项目结构

```
dsh-eat/
├── index.html            # 页面入口（标准入口名，仅含 HTML 骨架）
├── README.md             # 项目说明（本文件）
├── css/                  # 样式目录（按职责拆分）
│   ├── base.css          # 基础样式
│   ├── layout.css        # 布局样式
│   ├── components.css    # 组件样式
│   └── responsive.css    # 响应式样式
└── js/                   # 脚本目录（按职责拆分）
    ├── data.js           # 数据模块
    ├── utils.js          # 工具函数模块
    ├── state.js          # 全局状态与 DOM 引用模块
    ├── menu.js           # 菜单树渲染模块
    ├── views.js          # 内容区视图渲染模块
    ├── modal.js          # 模态框模块
    ├── index-panel.js    # 手机端索引抽屉模块
    └── app.js            # 应用入口模块
```

## 每个文件的作用

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面入口（标准入口名）。只保留 HTML 骨架（左侧边栏、右侧主内容区、模态框、手机端索引按钮与遮罩），通过 `<link>` 引入 4 个样式文件、通过 `<script>` 按依赖顺序引入 8 个脚本文件。 |
| `css/base.css` | 基础样式：全局重置（margin/padding/盒模型）、页面字体与背景、最外层容器 `.app`。 |
| `css/layout.css` | 布局样式：整体两栏布局——左侧深色边栏（品牌区、菜单树、底部营业信息）与右侧主内容区（页头、可滚动内容区）。 |
| `css/components.css` | 组件样式：内容区各视图的组件——菜品卡片网格、店面图片横幅、公告板、食堂介绍页（含多图轮播：左右按钮、圆点指示器）、随机推荐卡片、菜品详情模态框、空状态。 |
| `css/responsive.css` | 响应式样式：针对 ≤1024px（平板）、≤768px（手机横屏）、≤480px（小屏手机）三档断点调整布局、字号与间距；其中 ≤768px 区块包含「顶部下拉索引抽屉」的全部样式（右上角按钮、遮罩、抽屉滑出动画）。 |
| `js/data.js` | 数据模块：集中存放全部静态数据——门店图标库、三个食堂的完整数据（食堂→楼层→门店→菜品）、每个食堂的多张轮播图（images）、每个门店的店面图（image）、默认公告、推荐语库。 |
| `js/utils.js` | 工具函数模块：公告读取（直接返回数据文件中的默认公告）、食堂/楼层/门店查找、菜品汇总与随机选取、时间格式化、图标轮换。 |
| `js/state.js` | 全局状态与 DOM 引用模块：集中管理共享运行状态（当前菜单、展开的食堂/楼层、选中的门店、上次随机菜品）与页面所有 DOM 元素引用。 |
| `js/menu.js` | 菜单树渲染模块：根据数据与状态构建并渲染左侧导航（功能项 + 食堂三级树），处理展开/收起/选中交互。 |
| `js/views.js` | 内容区视图渲染模块：渲染公告板、食堂介绍页（多图轮播：自动播放、左右切换、圆点跳转、悬停暂停、触摸滑动）、随机推荐、门店菜品网格（上方带店面图片横幅），并提供统一调度入口 `renderAll()`。 |
| `js/modal.js` | 模态框模块：控制菜品详情模态框的打开/关闭，并绑定关闭按钮、点击遮罩、Esc 键三种关闭方式。 |
| `js/index-panel.js` | 手机端索引抽屉模块：控制右上角「索引」按钮的展开/收起、遮罩与 Esc 关闭、选中门店或功能项后自动收起；桌面端不生效。 |
| `js/app.js` | 应用入口模块：页面启动时初始化状态并执行首次渲染；同时提供全局图片加载失败的兜底处理（显示占位图）。 |

## 脚本加载顺序（重要）

脚本之间通过全局变量/函数协作，必须按下述顺序加载（`index.html` 中已排好）：

```
data.js → utils.js → state.js → menu.js → views.js → modal.js → index-panel.js → app.js
```

- `data.js` 提供数据 → `utils.js` 提供函数 → `state.js` 提供状态与 DOM 引用；
- `menu.js` / `views.js` 使用上述三者完成渲染；
- `modal.js` 在加载时绑定模态框事件；
- `index-panel.js` 在加载时绑定手机端索引抽屉事件；
- `app.js` 最后执行初始化。

## 如何运行

无需安装任何依赖，直接用浏览器打开 `index.html` 即可（双击文件，或拖入浏览器窗口）。
部分菜品图片来自 `picsum.photos`（需联网）；图片加载失败时页面会自动显示占位图。
公告直接取自 `js/data.js` 中的 `DEFAULT_BULLETINS`：修改数据文件后刷新页面即生效，不依赖浏览器存储。

**手机端体验**：屏幕 ≤768px 时，顶部收窄为「品牌 + 右上角索引按钮」的顶栏，点击「索引」
按钮从顶部滑出下拉抽屉（含全部导航：公告 / 今天吃什么 / 三个食堂三级菜单），再次点击
按钮、点击遮罩或按 Esc 收起；选中某个门店或功能项后抽屉自动收起。桌面端（>768px）
布局与交互保持不变。

> 说明：`index.html` 是项目唯一入口（部署到服务器时默认首页即此文件），打开它即可使用。
